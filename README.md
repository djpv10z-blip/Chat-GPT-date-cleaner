# ChatGPT Date Cleaner — v1.2.0

**Unofficial Chrome extension · Estensione non ufficiale**

Identify ChatGPT conversations created **and** updated before a date you choose, review the list, and optionally request their deletion with explicit safeguards.

> **EXPERIMENTAL — USE AT YOUR OWN RISK.** This independent project is **not affiliated with, supported by, or approved by OpenAI**. It uses undocumented ChatGPT APIs, which can change at any time. Deletion can be irreversible. Do **not** publish or use on important data without a full export and a successful one-chat test. A successful API response does not independently prove final data erasure from OpenAI systems.

## What's new in v1.2

- **Movable window:** drag the green title bar to reposition within your browser window; supports pointer/touch interactions.
- **Minimize:** press **−** to collapse the window into a floating 🧹 icon, then click the icon to restore; you can also drag the icon.
- **8 languages:** Italiano, English, Español, Русский, 日本語, 简体中文, العربية (RTL), Français.
- **First-run language selection:** select your language the first time you open the window. Your selection is stored locally using Chrome's extension storage; press **🌐** to change it later.
- **Disclaimer before each deletion:** clicking either delete button opens an independent, non-official software and risk notice. The user must **check acceptance** and **type a confirmation phrase**; Cancel leaves everything untouched. The disclaimer does not remove non-excludable legal rights.
- **Recheck before DELETE:** each candidate's creation/update dates are fetched again from ChatGPT before the removal request. Missing dates or updated chats cause the deletion process to stop rather than proceeding blindly. This safeguard may also stop deletion if the internal API response format changes.
- Date filtering uses **your browser's time zone** (shown beside the chosen date), not a fixed Italy time zone. The cutoff day itself is preserved.

## Installation (Chrome)

1. Download the packaged ZIP attached to **Releases**, and extract it into a stable folder.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
5. Navigate to `https://chatgpt.com` and refresh the page.
6. Press the floating **Chat cleanup** button.

> Installing from GitHub involves manual developer-mode loading. This is **not** a Chrome Web Store installation, and automatic updates are not provided.

## Safe use

1. In ChatGPT, go to **Settings → Data Controls → Export Data** and verify that you have a **full** backup. The CSV generated by the extension is **not** a backup of chat contents.
2. Pick your language and choose the date **from which chats must be preserved**, inclusive.
3. Scan chats (no deletions are made during the scan), optionally including archived or Project chats.
4. Review the candidate list and export the CSV. To delete, check the backup confirmation.
5. Start with **Delete 1 test chat**. Carefully read the disclaimer, tick its acceptance checkbox, enter the exact confirmation phrase, and check the result in ChatGPT.
6. Run a **new scan** and download a **new CSV** before further deletion.

The extension only allows deletion of chats reported as **both created and updated before** the selected date. Chats with missing creation or modification dates are excluded. Project chats are excluded by default where the available metadata identifies them; metadata may be incomplete.

## Technical limitations

- The tool uses **internal, undocumented** endpoints, not an official public deletion API. They may fail or change without notice.
- Each deletion is preceded by a second date check; if the server does not provide parseable timestamps, the tool stops without sending that deletion request.
- The UI permits only 350 visible table rows for performance; the CSV includes the complete candidate list.
- A successful HTTP response indicates only that the request was accepted; always re-scan and check the account.
- During an ongoing deletion, you may **minimize** and restore the window but not close it. Use **Stop** to request stopping after the active request.
- Avoid making edits to target conversations while a deletion batch is running. Project identification relies on internal metadata and may be incomplete.

## Privacy and permissions

The extension requests the Chrome **`storage`** permission only to save the preferred language locally. It has a content script on `https://chatgpt.com/*`; it does not request access to other websites. It reads the logged-in ChatGPT session to make requests **only to chatgpt.com**; it does not store passwords or session tokens in persistent storage and has no third-party analytics or telemetry. Generated CSV files are local downloads. See [`PRIVACY.md`](PRIVACY.md).
